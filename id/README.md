# The Missing Semester of Your CS Education

[![Build Status](https://github.com/missing-semester/missing-semester/actions/workflows/build.yml/badge.svg)](https://github.com/missing-semester/missing-semester/actions/workflows/build.yml) [![Links Status](https://github.com/missing-semester/missing-semester/actions/workflows/links.yml/badge.svg)](https://github.com/missing-semester/missing-semester/actions/workflows/links.yml)

Situs web untuk [The Missing Semester of Your CS Education](https://missing.csail.mit.edu/)!

Kontribusi sangat diterima! Jika Anda memiliki suntingan atau konten baru untuk ditambahkan, silakan
buka issue atau kirimkan pull request.

## Pengembangan

Untuk membangun dan melihat situs secara lokal, jalankan:

```bash
bundle exec jekyll serve -w
```

Jika Anda lebih suka mengembangkan situs dalam container Docker (misalnya, untuk menghindari
keharusan memasang Ruby dan dependensinya di mesin host Anda), jalankan:

```bash
docker compose up --build
```

Lalu, bernavigasi ke <http://localhost:4000> di mesin host Anda untuk melihat
situs web. Jekyll akan membangun ulang situs web saat Anda membuat perubahan pada berkas.
