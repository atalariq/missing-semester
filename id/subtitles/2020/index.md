## Catatan transkrip sumber

Transkrip sumber memuat beberapa kekeliruan pengenalan suara. Terjemahan mempertahankan isi dan istilah sumber; catatan berikut membantu membacanya tanpa mengubah contoh kode secara diam-diam:

* Q&A, cue 0171: transkrip menyebut pemisah PATH sebagai titik koma. Pada shell Unix yang dibahas, pemisahnya adalah titik dua.
* Q&A, cue 0571: teks Inggris berbunyi “couldn’t install BSD”, tetapi konteks paragraf dan catatan kuliahnya merekomendasikan BSD. Terjemahan “bisa memasang BSD” mengikuti konteks tersebut; ini merupakan interpretasi atas kemungkinan kesalahan transkrip, bukan verifikasi audio.
* Q&A, cue 0642: “semicolon WQ” tampaknya merujuk pada command Vim `:wq`.
* Shell Tools, cue 0253: pemeriksaan file ditulis `-F` dalam transkrip; contoh yang dimaksud kemungkinan `-f`.
* Shell Tools, cue 0728: kalimat tentang asal fitur autosuggestion tidak jelas dalam transkrip. Konteks catatan kuliah membahas fish.
* Shell Tools, cue 0754: “facily match” kemungkinan merupakan pengenalan suara yang keliru atas fuzzy matching pada broot.
